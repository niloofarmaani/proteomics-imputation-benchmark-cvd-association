# Own-data workflow execution example

Explicitly synthetic data, generated by write_worked_example(). All existing
workflow code was reused unchanged. The source notebook is
../../notebooks/impute_your_own_data.ipynb; its executed version is beside it.

The input has 256 samples and 60 numeric variables. The complete reference
contains 160 samples. All 18 tuning trials and 81 final benchmark fits
completed across nine methods. Validation selected Iterative. Its final refit
used all 256 original samples and filled 1,054 native missing measurements.
Observed values, leading-zero IDs and row/column ordering were checked.

best_imputed_dataset.csv contains only synthetic example measurements and IDs.
No user-uploaded or MyoVasc participant data are included. The notebook's
optional example mode regenerates the original incomplete input. Detailed
masks, benchmark completions, logs and studies are in the full run archive
created by execution, not this summary directory.

The first, smaller example hit an existing Transformer all-missing-batch error;
that implementation was not modified. See ../../docs/OWN_DATA.md and
../../docs/VALIDATION.md. Fresh Colab UI and full-budget execution remain untested.
