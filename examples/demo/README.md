# Executed public-data demo

Summary outputs from the validated 160-patient, 60-feature TCGA-UCEC run. See ../../docs/VALIDATION.md for execution scope and limitations. Complete masks/matrices are generated and exported when rerunning the notebook.

The original demo manifest predates the addition of source-code hashes and relative matrix paths to the runner. Relative paths in reconstruction.csv describe the full run export, not files bundled in this summary-only directory.
