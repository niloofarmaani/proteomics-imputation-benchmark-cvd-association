1. Open the notebook using the badge and authorize GitHub access if prompted.
2. Download the [repository source ZIP](https://github.com/niloofarmaani/proteomics-imputation-benchmark-cvd-association/archive/refs/heads/main.zip) while signed in to GitHub.
3. Run the first code cell and upload that ZIP. It can be the GitHub download or the previously supplied imputation-reproducibility.zip.
4. Run the setup cell. Restart the runtime once if the cell reports changed loaded packages; then rerun from the beginning.
5. Keep MODE='demo' for the first full test. Save the exported result archive before the runtime ends.

Opening a notebook from GitHub does not clone its repository into the Colab filesystem. This upload step supplies the source modules used by the notebook without storing GitHub credentials in the runtime.
